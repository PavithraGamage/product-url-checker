How a redirect target is chosen

Original URL .../catalog/product/view/id/1052/s/leo-sunglasses/category/8/locations.html is checked first. If it's already redirecting, that target is reported as-is. Otherwise the product slug (leo-sunglasses) is extracted and rebuilt as /leo-sunglasses.html, which is checked in turn: 200 → use it as-is · redirects → use its final target · 404 → fall back to /sunglasses.html if the slug contains "sunglass", otherwise /glasses.html.
